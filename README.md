# Renju ♥ Rasathi — Wedding Invitation

A mobile-friendly wedding invitation made for GitHub Pages.

## Quick edit
Open `index.html` and change the line:
`തീയതി ഇവിടെ ചേർക്കാം`

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. GitHub will give you a shareable website link.

The venue Google Maps link is already connected to the supplied QR code destination.
